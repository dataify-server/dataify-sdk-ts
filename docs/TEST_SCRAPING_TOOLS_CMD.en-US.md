# Dataify TypeScript SDK Scraping Tools Test Guide (CMD English Version)

This guide tests Dataify scraping runtime APIs.

For these tests, you need a Dataify API Key.

CMD and PowerShell use different command syntax. The commands in this document are written for Windows CMD.

## 1. What You Need

Before starting, make sure you have:

- A Windows computer.
- A Dataify API Key.
- The SDK directory: `D:\dataify-TS-SDK`
- Node.js 18 or later.

## 2. Open a CMD Window

Method 1:

1. Press `Win + R` on your keyboard.
2. Type:

```text
cmd
```

3. Press Enter.

Method 2:

1. Open the Windows Start menu.
2. Search for `cmd`.
3. Click `Command Prompt`.

You should now see a black window, usually showing something like:

```text
C:\Users\Administrator>
```

## 3. Go to the SDK Directory

If you are not on drive D, switch to drive D first:

```cmd
D:
```

Press Enter.

Then go to the SDK directory:

```cmd
cd \dataify-TS-SDK
```

You can also do it in one command:

```cmd
cd /d D:\dataify-TS-SDK
```

Check the current directory:

```cmd
cd
```

Expected output:

```text
D:\dataify-TS-SDK
```

## 4. Check Node.js

Run:

```cmd
node -v
```

If you see something like:

```text
v20.11.0
```

Node.js is installed.

Check npm:

```cmd
npm -v
```

If it prints a version number, npm is available.

If you see an error like `node is not recognized`, install Node.js 18 or later first.

## 5. Install Dependencies

Run this in the SDK directory:

```cmd
npm install
```

Wait until it finishes.

It is safe to run this again if dependencies were already installed.

## 6. Generate Tool Code

Run:

```cmd
npm run generate
```

Expected output:

```json
{
  "scraper": 88,
  "serp": 25,
  "total": 113
}
```

Meaning:

- `scraper`: 88 Scraper tools.
- `serp`: 25 SERP tools.
- `total`: 113 generated scraping tool methods.

## 7. Type Check

Run:

```cmd
npm run check
```

If there is no error, the TypeScript type check passed.

## 8. Build the SDK

Run:

```cmd
npm run build
```

This should generate:

```text
D:\dataify-TS-SDK\dist
```

The tests below import the SDK from `dist/index.js`.

## 9. Set Your API Key

In CMD, set an environment variable like this:

```cmd
set DATAIFY_API_TOKEN=your API Key
```

Example:

```cmd
set DATAIFY_API_TOKEN=df_xxxxxxxxxxxxxxxxxxxxx
```

Notes:

- Do not add spaces around `=`.
- Do not share your API Key.
- Do not commit your API Key into public code.
- This environment variable only works in the current CMD window. If you close the window, set it again.

Check whether it was set:

```cmd
echo %DATAIFY_API_TOKEN%
```

If it prints your API Key, it is set correctly.

## 10. Mock Test: No Real API Call, No Credit Cost

This test only checks the URL, headers, and body generated by the SDK.

Run:

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const calls = []; const fetchImpl = async (url, init) => { calls.push({ url: String(url), init }); return new Response(JSON.stringify({ ok: true }), { status: 200 }); }; const client = new DataifyClient({ apiKey: 'TEST_API_KEY', fetchImpl }); await client.tools.google({ q: 'Dataify', json: '1' }); await client.tools.amazonProductByUrl({ url: 'https://www.amazon.com/dp/B000000000' }); await client.webUnlocker.request({ url: 'https://example.com', type: 'html', js_render: false }); console.log(JSON.stringify(calls.map((c) => ({ url: c.url, auth: c.init.headers.Authorization, body: c.init.body?.toString?.() || '[FormData or JSON]' })), null, 2)); })"
```

You should see three request URLs:

```text
https://scraperapi.dataify.com/request
https://scraperapi.dataify.com/builder?platform=1
https://webunlocker.dataify.com/request
```

The authorization header should contain:

```text
Bearer TEST_API_KEY
```

If this passes, the local SDK request format is basically correct.

## 11. Real Test 1: SERP Google Search

This calls the real API and may cost credits.

Run:

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const res = await client.tools.google({ q: 'Dataify', json: '1' }); console.log(JSON.stringify(res, null, 2)); })"
```

If successful, it should return Google search result JSON.

If authentication fails, check:

- Whether your API Key is correct.
- Whether you ran `set DATAIFY_API_TOKEN=your API Key`.
- Whether the API Key is expired or disabled.

## 12. Real Test 2: Web Unlocker

Run:

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const res = await client.webUnlocker.request({ url: 'https://example.com', type: 'html', js_render: false }); console.log(JSON.stringify(res, null, 2)); })"
```

If successful, it should return a Web Unlocker response.

## 13. Real Test 3: Scraper Tool

Scraper tools usually create a task. They may not return the final data immediately.

Example: Amazon product details.

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const res = await client.tools.amazonProductByUrl({ url: 'https://www.amazon.com/dp/B000000000' }); console.log(JSON.stringify(res, null, 2)); })"
```

Notes:

- The sample URL is only a placeholder. Use a real Amazon product URL.
- If a task id is returned, the task was created successfully.
- Download the final result after the task is finished.

## 14. Download Task Result

If you have a task id such as:

```text
task_id_123
```

Download JSON:

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const response = await client.scraper.downloadTaskFile('task_id_123', 'json'); console.log('ok:', response.ok); console.log('status:', response.status); console.log(await response.text()); })"
```

For CSV or XLSX, do not print the binary content to the terminal. Check the status first:

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const response = await client.scraper.downloadTaskFile('task_id_123', 'xlsx'); console.log('ok:', response.ok); console.log('status:', response.status); })"
```

### 14.3 Query Scraper Task Status

Use the task ID returned by a Builder request. `处理中`, `成功`, and `失败` are successful API responses; HTTP 400 means the task does not exist or is not owned by the API key, while HTTP 403 means the task ID is missing or the API key is invalid.

```cmd
node -e "import('./dist/index.js').then(async ({ DataifyClient }) => { const client = new DataifyClient({ apiKey: process.env.DATAIFY_API_TOKEN }); const result = await client.scraper.getTaskStatus('task_id_123'); console.log(JSON.stringify(result, null, 2)); })"
```

## 16. Common Issues

### 16.1 `Cannot find module './dist/index.js'`

Reason: the SDK has not been built yet.

Fix:

```cmd
npm run build
```

### 16.2 `Missing apiKey`

Reason: API Key is not set.

Fix:

```cmd
set DATAIFY_API_TOKEN=your API Key
```

### 16.3 `401` or Authentication Error

Possible reasons:

- API Key is incorrect.
- API Key is expired.
- API Key is disabled.



### 16.4 Environment Variable Does Not Work

Make sure you run this in the same CMD window:

```cmd
set DATAIFY_API_TOKEN=your API Key
```

Then run the test command in that same window.

If you close the CMD window, set it again.

### 16.5 Garbled Chinese Text

This document is encoded in UTF-8. If CMD shows garbled text, run:

```cmd
chcp 65001
```

Then reopen the document or rerun the command.

## 17. Success Criteria

The scraping SDK can be considered basically usable if:

- `npm run generate` outputs `total: 113`.
- `npm run check` has no errors.
- `npm run build` has no errors.
- Mock test prints the three correct endpoint URLs.
- `client.tools.google()` succeeds against the real API.
- `client.webUnlocker.request()` succeeds against the real API.
- At least one Scraper tool successfully creates a task.
